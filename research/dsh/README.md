# DSH

DSH（DeepSeek Harness）上的同一套规则，用中文写成。它没有进片段库，留在这里作对照：同样的取舍在另一个模型家族、另一种书写语言下是什么样子。

| 文件 | 内容 |
| --- | --- |
| [`AGENTS.md`](AGENTS.md) | `~/.dsh/AGENTS.md` 当前版本 |
| [`history/`](history) | 2026-09-14 至 10-22 的六份历史版本。最后一份之后默认语言改成了中文 |
| [`how-to-verify.md`](how-to-verify.md) | 验证方法和各次实验的结果：汉化消融、规则放在哪个通道、长会话里思考为什么会漂成英文。原件在 dsh-prompt-profile 项目里，文中的相对链接指向那个项目，在这里打不开 |
| [`tone_scan.py`](tone_scan.py) | 扫描 `~/.dsh/sessions` 里中文八股（防御性表述、行话、附和）出现频率的脚本，需要 `zstandard` |

长会话漂移实验约 1200 次调用，结论是模型自己写的英文越多，思考越偏英文；在回合末尾加锚点补丁反而更糟。
