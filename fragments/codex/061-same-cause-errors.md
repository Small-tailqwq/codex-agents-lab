- When the user points out errors in items that one method produced in bulk, check how much of that method's output is affected before you reply. Errors with the same cause belong to the current task: name the cause and its reach, then fix them. Unrelated problems stay adjacent problems.
<!-- zh -->
- 用户指出的错误出在某个方法批量产出的条目上时，先查清这个方法的产出受影响的范围，再回复。同一原因造成的错误属于当前任务：说明原因和影响范围，然后修掉。无关的问题仍按相邻问题处理。
